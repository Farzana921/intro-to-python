# Secret Auction (Python)

A simple command-line program for a secret auction.

## Features

* Multiple users can place bids
* Bids are hidden from others
* Finds the highest bid
* Shows the winner

## How to Run

```bash
python secret_auction.py
```

## Usage

* Enter your name
* Enter your bid
* Type `yes` if there are more bidders
* Type `no` to finish

## Example

```
Ali
10
yes
Sara
25
no
Winner: Sara with $25
```
