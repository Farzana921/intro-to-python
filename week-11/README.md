# Calculator 

A simple command-line calculator built with Python.

## Features

* Add, subtract, multiply, divide
* Continue calculations with previous result
* Restart anytime

## How to Run

```bash
python calculator.py
```

## Usage

* Enter first number
* Choose operation (+, -, *, /)
* Enter next number
* Type `y` to continue or `n` to restart

## Example

```
10
*
5
= 50
```
